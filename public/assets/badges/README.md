# Badges Directory

This directory contains certification and association badges displayed on the Taylor Movers website.

## Required Badge

### IAM Trusted Moving Professional Badge
- **Filename:** `iam-trusted-badge.png`
- **Location:** `/public/assets/badges/iam-trusted-badge.png`
- **Dimensions:** 150px width x 180px height (or proportional)
- **Format:** PNG with transparent background preferred
- **Usage:** Displayed in the footer under "Associations" section

The badge should be the official IAM (International Association of Movers) "Trusted Moving Professional" badge featuring:
- IAM logo with globe icon
- "TRUSTED" text on gold/bronze ribbon
- "Moving Professional" text at bottom
- Blue shield background design

## Adding the Badge

1. Save the IAM badge image as `iam-trusted-badge.png` in this directory
2. Ensure the image dimensions are appropriate (150x180 recommended)
3. The image will automatically appear in the footer
